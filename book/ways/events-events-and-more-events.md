
# Events, Events and more Events

We want students engaged through and through, and the timetable alone cannot do that. Classes exercise one set of capacities. Events give students the opportunities to express themselves that classes rarely do: organising, performing, competing, presenting, hosting, failing in public and recovering.

So the belief is plural on purpose: lots and lots of events. And the second half matters more than the first: organized for the students, and by the students. An event run by staff for student attendance is a service students consume. When a student runs it, the event itself becomes the lesson: budgeting, negotiating, leading peers, owning an outcome in front of an audience.

Where we stand today: this page describes where Kalvium wants to be, not a claim about where every campus is. Which makes it an instruction, if you run a campus, this is a direction to push, not a box already ticked.

Count the events on your campus last month that a student led end to end. Is the number growing?
