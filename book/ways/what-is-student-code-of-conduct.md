
# What is student code of conduct?

The code of conduct itself is a process document, and processes change, so this book does not contain one. What does not change is that every campus must have one, published, and with four properties.

It states what is expected of a student here, plainly. It states what is not acceptable, just as plainly. It states what happens when the line is crossed, the penalties, in advance, so that no consequence ever arrives as a surprise.

Then the fourth property, the one that makes the first three work: students are taken through it and understand it. A code that lives unread on a portal protects nobody. A student who knew the rule and the consequence, and chose anyway, made a choice. That distinction is what a code of conduct exists to make possible.

Could every student on your campus name what happens after a first plagiarism case? If not, the code is not yet doing its job.
