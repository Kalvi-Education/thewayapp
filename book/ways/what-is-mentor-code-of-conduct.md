
# What is mentor code of conduct?

Mentors hold real power over students: grades, references, attention, tone. Power over young adults needs a written boundary, not an assumed one.

So a written mentor code of conduct must exist, every mentor must know it, and it must do three things plainly. State expected conduct, in the classroom and outside it. Draw the boundaries of the mentor-student relationship, including the digital ones. And state what crossing them leads to.

The document itself is owned and evolved by the program delivery team, because its specifics will change with time and context. What does not change is that it exists, that it is current, and that every mentor knows it.

If you mentor here and have not read yours, that is your first task after this page.
